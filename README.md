# Walmart-Data-Analysis

This analysis explores Walmart store sales data to identify key drivers of revenue performance. It visualizes sales trends over time, compares store performance across regions, evaluates the impact of holidays on sales, and analyzes customer purchasing behavior. The project also examines seasonal patterns, highlights the most and least profitable departments, and provides insights to support inventory planning and business decision-making.
